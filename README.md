# rayhan-portfolio

Single-file portfolio (`index.html` + `assets/`). Media lives in `assets/` and is wired through `MEDIA.music` / `MEDIA.videos` in the script.

## ASCII art credits

- iPod (music player widget): by **Christopher Johnson** — https://asciiart.website/art/2600
- TV (video player widget): by **Joan Stark (jgs)** — https://asciiart.website/art/7479
- Radio (DJ section): source: https://asciiart.website/art/3619

## Notes

- Music clips in `MEDIA.music` are 45-second preview cuts of Rayhan's own tracks.
- Ink/doodle effect on the left paper column is a vanilla-canvas port (technique only) inspired by InkField (Aluan Wang) — see the comment in `index.html`.
